# PPT Planning Summary

本文件只供叙事结构与逐页大纲阶段使用。规划阶段不需要读取完整 Skill、
布局、主题、组件、图片或检查清单；HTML 阶段会另行应用锁定的 Design Pack。

## 叙事结构

- 以任务目标、受众与核心主题为唯一事实边界，不补造输入中不存在的数据。
- 先给结论和决策请求，再安排证据、方案、风险与下一步，避免按资料目录机械罗列。
- 每一部分只承担一个明确作用，并说明它如何推动受众理解或行动。
- 缺少数字、日期、部门或来源时，删除该指标或明确写“数据待确认”；不得使用
  `XX`、`XXX`、`TBD`、默认日期/部门等占位内容冒充已确认事实。

## 逐页大纲

- 每页包含一个短标题、一个页面目的和可直接渲染的正文/列表。
- 标题表达该页结论或问题，不使用“背景介绍”“解决方案”等空泛目录词。
- 一页只保留一个视觉焦点；正文优先 3–5 个短要点，信息过多时拆页。
- 资源只能引用输入中冻结的 `resources://` URI；没有合适资源时使用空数组。
- 数字、预算、比例、日期与 KPI 必须能在任务资料中找到来源；未提供时不得推断。
- 不编写 HTML、样式、页面 ID、模板选择或检查结果。

完成后直接提交当前阶段要求的 JSON，不要继续请求其他 Skill 文件。
