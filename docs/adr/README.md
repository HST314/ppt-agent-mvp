## MVP 非目标护栏

- 不实现统一主 Agent、全局任务看板或审批收件箱。
- 不实现 PDF/PPTX 导出和移动端适配。
- 不解析客户原始 PDF、Office、音视频资料。
- 不要求模型查看图片或页面截图。
- 不支持同一主任务下多个 PPT Agent 实例。
- 不引入分布式队列、微服务、远程对象存储或多主机调度。
- 不把具体 HTML 设计方法写死在运行内核；由版本化 Skill 提供。
- 不以生成全稿、检查通过或文件写入替代用户确认交付。
