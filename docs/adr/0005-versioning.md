# ADR-0005：版本与回退

状态：已采纳  
日期：2026-08-11

## 决策

叙事、大纲、样品、全稿、检查和交付均追加新版本，已成功版本不可原位覆盖。产物以规范化内容 hash 标识；checkpoint 引用不可变版本。回退通过从历史版本派生新候选分支实现，已交付版本保持不变。

hash 只用于内容寻址，不表达先后关系。当前输入、叙事、大纲、样品、全稿和检查由成功提交的领域事件显式解析；处置记录携带单调 `sequence`，同一问题以最大序号为当前处置；展示时间线按产物 `version`/时间字段排序。

## 理由与后果

支持审计、局部修改、失败恢复和交付后继续编辑。需要显式记录父版本、动作、操作者、时间、影响范围及依赖 hash；失败事件不得推进最后成功指针。
